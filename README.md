# Parameterized Serial Binary Adder in Verilog HDL

## Overview

This project implements a **Parameterized Serial Binary Adder** in **Verilog HDL**. The design performs binary addition serially by processing one bit during each clock cycle. The architecture consists of two parameterized shift registers, a full adder, and a carry flip-flop.

The design is parameterized, allowing different operand widths by modifying the parameter value (`N`) without changing the overall architecture. The project was designed, simulated, and verified using **Xilinx Vivado**.

# Project Architecture

The design consists of the following modules.

## Shift Register (`shift_register`)

Two parameterized shift registers are used.

### Shift Register A

- Stores Operand A
- Receives generated sum bits
- Produces the final sum

### Shift Register B

- Stores Operand B
- Supplies one bit to the Full Adder
- Shifts right during each shift operation

---

## Full Adder (`full_adder`)

Performs single-bit binary addition.

### Inputs

- Operand A
- Operand B
- Carry In

### Outputs

- Sum Bit
- Carry Out

---

## Carry Register (`d_ff`)

Stores the carry generated by the Full Adder.

The stored carry is supplied as the Carry-In during the next clock cycle.

---

## Top Module (`serial_adder`)

Integrates all submodules into a complete parameterized serial binary adder.

### Inputs

- Clock
- Reset
- Load
- Shift
- Operand A
- Operand B

### Outputs

- SUM
- Carry Final

---

# Working Principle

1. Reset initializes all registers.
2. The **load** signal loads operands A and B into the shift registers.
3. The **shift** signal enables serial shifting.
4. The Full Adder performs one-bit addition during each clock cycle.
5. The generated carry is stored in the D Flip-Flop.
6. Shift Register A stores the generated sum bits.
7. Shift Register B shifts right during every shift operation.
8. After all bits are processed, the final SUM and Carry Final outputs become available.
